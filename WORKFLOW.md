

\# The Green Corner – Rebuild Workflow



\## Project Overview



The Green Corner is a plant care and gardening website. This repository contains two versions of the website:



\- `plain-css/` – The original website built with HTML and CSS.

\- `tailwind/` – The rebuilt website using Tailwind CSS.



\## Rebuilding Process



1\. Reviewed the original HTML and CSS design.

2\. Created a separate Vite project for the Tailwind version.

3\. Installed Tailwind CSS and its Vite plugin.

4\. Configured Tailwind CSS in the Vite project.

5\. Rebuilt the homepage using Tailwind utility classes.

6\. Reused the original images in the Tailwind version.

7\. Added responsive layouts for desktop, tablet, and mobile screens.

8\. Tested the website in the browser and checked the responsive layout.



\## Technologies Used



\- HTML5

\- CSS3

\- Tailwind CSS

\- JavaScript

\- Vite

\- Git and GitHub



\## Testing



The rebuilt website was opened in the browser and checked at desktop and mobile screen sizes. The images and page layout were also verified.
